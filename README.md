\# CampusNotes



\## Project Overview



CampusNotes is a simple academic notes management application designed to help students create, organize, and manage their study notes in one place.



\## Features



\- Add academic notes.

\- Organize notes by subject.

\- View saved notes.

\- Delete unwanted notes.

\- Store notes using browser Local Storage.



\## Project Objectives



\- Provide a simple interface for managing academic notes.

\- Make it easier for students to organize study materials.

\- Understand the fundamentals of web development.

\- Apply version control concepts using Git and GitHub.



\## Technologies Used



\- HTML – Structure of the application.

\- CSS – Styling and layout.

\- JavaScript – Application functionality.

\- Local Storage – Saving notes in the browser.



\## Installation and Setup



1\. Clone or download the repository.

2\. Open the project folder in VS Code.

3\. Open `index.html` in a web browser.

4\. Start creating and managing your academic notes.



\## Project Structure



\- `index.html` – Main application page.

\- `style.css` – Application styling.

\- `script.js` – Application functionality.



\## Version Control and Collaboration



This project was created as part of the Version Control System (CSE25303) assignment.



Git and GitHub were used to practise:



\- Repository creation and management.

\- Branching and merging.

\- Commits and version history.

\- Collaboration using forks and pull requests.



\## Contribution Guidelines



1\. Fork the repository.

2\. Create a separate feature branch.

3\. Make the required changes.

4\. Commit and push your changes.

5\. Submit a pull request for review.



\## Project Purpose



The purpose of this project is to develop a basic academic notes application while learning Git, GitHub, and collaborative software development workflows.
